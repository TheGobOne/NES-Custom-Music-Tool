Turns NES music (NSF / NSFe files) into a music pack for a Zelda randomizer. Everything runs in this page; nothing is uploaded anywhere.

How to use
  1. Pick the game your pack is for: Zelda 1 (ZORA) or Zelda 2 (Z2R).
  2. Add your music. Drop NSF or NSFe files (or a zip / 7z / folder of them), or an existing .json5 pack onto the page. For a plain .nsf, add its .m3u playlist too so the tracks get names and the sound effects are left out. An .nsfe has them built in.
  3. Check the tracks. Play them, tick the ones you want, and tag each with where it can play ("Use for"). Tracks that don't loop are cut at the max length. If a track sounds buzzy in the game, try its Smooth box. Search finds games and tracks; the Radio plays your ticked tracks at random.
  4. Normalize volumes to set every track to the same loudness, so the music sits right against the game's sound effects. Adjust the target level if it's too loud or quiet in the game, and fix any single track with its Vol box.
  5. Export the .json5 pack and load it in the randomizer. Keep your master pack: add more games to it later, and use Re-import when the tool is improved to rebuild tracks from the original files without losing your ticks and tags.

Re-import: pick the original NSF / NSFe files (or their zip, 7z or folder) of games already in the list. Their tracks are converted fresh, at Vol 100% (normalize again afterwards), and keep which tracks are ticked, their Use for tags, names and Loop. Use it when a pack's tracks have been rescaled too often and sound thin.
Track names: an .nsfe file has them built in. For a plain .nsf, add its .m3u playlist files with it (adding the whole folder or archive does that). Either way only the playlist's tracks are listed (rips also contain sound effects).
Smooth (a box on each track): some songs make the pulse channels' volume jump up and down every frame or two, which can sound buzzy in the game even when the preview sounds fine (FF2's battle theme does this). Smooth averages that flicker out. The notes, timing and loop stay the same, and you hear the result in Play. A track with no flicker is left alone (the box unticks itself). Leave it off for songs whose tremolo or echo is meant to be there. It is baked into the export, so keep your master pack if you want to undo it later.
2. Check tracks
Show help
Normalize measures how loud each track plays and sets its Vol % so it reaches the target level: a fixed loudness, so tracks you add later match ones you normalized before. Tracks already within the Safety range of the target (±10% unless you change it) are within range and left exactly as they are, so normalizing a library again changes nothing. Lower the target to make everything quieter in the game (the tool remembers it). A track too quiet to reach the target is boosted only as far as it stays clean: until its loudest note is at full volume (marked in Notes). Further than that, its fades get cut off. The triangle channel (often the bass) has no volume control on the NES, so a track carried mostly by it can't get louder (or quieter).
Converted tracks under 15 seconds (usually jingles and sound effects) start unticked: play them and tick the ones you want.
"Use for" picks where may place each track. "Loop" repeats the track (from its loop point, or from the start for a track that normally plays once); unticked, it plays once and then goes silent. The tool also marks which pulse channel carries the melody (its guess: the higher-pitched one), so can keep it clear of the game's sound effects.
Radio
Games: all
Plays ticked tracks only, at the volume set in the list, so it sounds the way the game will. Each track fades in and out over 3 seconds. Starting or stopping a track by hand ends the radio.
Use for: what's covered
Counts ticked tracks only. Not every use needs a track, but the game sounds better when each has at least one (more gives more variety). Click a use to see its tracks.

3. Export
Both (beta): tag each track for ZORA, Z2R or both. Each export keeps only that game's tags: a track with no tag for the game is left out (in the ZORA export, tracks over ZORA's size limit are written switched off). Load the two masters back together to carry the tags on.
Export JSON5 saves everything into one file, one group per game. Export each game separately writes one file per game into a folder you pick (for example the randomizer's Music folder; files with the same name are replaced), or downloads them as a zip in browsers that can't write to a folder.
